# 레슨덱 (LessonDeck)

PDF 페이지 사이에 HTML 웹앱을 독립 페이지로 끼워 넣고, 모든 페이지 위에 S펜으로 판서하는 태블릿용 수업 리더입니다.
요구사항과 개발 단계는 [SPEC.md](./SPEC.md)를 따릅니다.

> 이 폴더는 `History-Board-Game` 저장소 안의 독립 프로젝트입니다. 루트의 보드게임(Next.js)과 의존성·빌드를 공유하지 않습니다.

## 현재 기능 (v0.14.0)

Phase 0(필기감 검증)에 태블릿 피드백(손가락 확대, 사이드 버튼 지우개, 페이지 관리), HTML·URL 페이지(F2·F3·F6), 유튜브 동영상 페이지, 저장·구글 드라이브 동기화, 이미지·동영상 페이지, 강의 모드, 텍스트 상자·하이퍼링크, 길게 누르기 메뉴를 더한 상태입니다.

**이미지 스티커 (v0.14)**

- 도구 막대의 **이미지 스티커** 단추(또는 페이지를 길게 눌러 "여기에 이미지 스티커")로 그림을 골라 지금 페이지 위에 붙임. 어느 페이지(PDF·빈 페이지·웹 페이지 등)에나 붙고, 여러 장도 한 번에. PC는 그림 파일을 끌어 놓거나 복사한 그림을 Ctrl+V
- 붙인 스티커: 끌어서 옮기기 · 모서리로 크기(비율 유지) · 위 동그라미로 돌리기(15°마다 살짝 붙음) · 빈 곳을 누르면 끝
- 위에 뜨는 막대: **자르기** · 90° 돌리기 · 좌우 뒤집기 · **꾸미기**(모양 사각/둥근/원, 테두리 없음/흰 스티커 테두리/색 5가지, 굵기, 그림자, 투명도, 상하 뒤집기) · 맨 앞으로/맨 뒤로 · 복사 · 잘라내기 · 복제 · 지우기(되돌리기 가능)
- 자르기: 그림 전체가 흐리게 보이고 보일 부분을 8개 손잡이로 정함(끌어서 옮기기도), 완료/원래대로/취소
- 스티커 위에 펜으로 그대로 판서할 수 있음(스티커는 필기 아래). 나중에 고치려면 스티커를 길게 누르거나(PC 오른쪽 클릭) 텍스트 모드에서 누르기
- 복사한 스티커는 다른 문서에도 붙음(그림 원본도 함께). 페이지 바 축소 이미지에도 보임

**페이지 복사·잘라내기·붙여넣기 (v0.14)**

- 페이지 바에서 고른 페이지의 **⋯** 단추(PC는 축소 이미지 오른쪽 클릭) → 복사 · 잘라내기 · 복제 · 앞/뒤에 붙여넣기 · 숨기기 · 삭제
- 페이지를 길게 눌러도 "이 페이지 복사 / 잘라내기", 복사해 둔 페이지가 있으면 "페이지 붙여넣기"
- 페이지 바 사이 **+** 메뉴 맨 위 "여기에 붙여넣기"로 원하는 자리에. PC는 Ctrl+V(지금 페이지 뒤)
- **다른 문서에도 그대로**: 필기·글상자·스티커와 원본 파일까지 함께 들어감. PDF 쪽은 그 쪽만 뽑아 넣어(벡터 그대로) 큰 PDF가 통째로 복사되지 않음. 다른 문서로 가던 페이지 링크는 글자만 남김
- 잘라내기는 알림의 "되돌리기"로 되살릴 수 있음

**홈: 폴더로 정리 (v0.13)**

- 홈의 **새 폴더**로 폴더를 만들고(이름 + 색 8가지), 폴더 안에 폴더도 만들 수 있음. 폴더 카드를 누르면 들어가고, 위 경로(`내 문서 › 동아시아사 › 3단원`)를 누르면 돌아감. 안드로이드 뒤로 가기 = 윗 폴더
- 폴더 안에 있을 때 위의 카드(PDF로 새 수업·빈 노트·파일 가져오기·샘플)로 만든 문서는 그 폴더에 들어감. 문서를 열었다 돌아오면 보던 폴더
- **옮기기**: 카드를 **길게 눌러 들린 채 끌어서** 폴더 카드나 위 경로에 놓기(PC는 마우스로 바로 끌기), 또는 카드 메뉴(⋮·길게 누르기·오른쪽 클릭)의 **폴더로 옮기기** → 폴더 나무에서 고르기(그 자리에서 새 폴더도 만듦)
- **선택**: 여러 문서·폴더를 골라(모두 선택 가능) 한 번에 옮기기·삭제. 고른 카드를 끌면 고른 것이 모두 옮겨짐
- 폴더 메뉴: 열기 · 이름·색 바꾸기 · 옮기기 · 삭제(**폴더만 지우기** = 안의 것은 윗 폴더로 꺼냄 / **안의 문서까지 모두 삭제**)
- **찾기**: 모든 폴더의 문서·폴더 이름으로 찾고, 결과에 들어 있는 폴더를 보여 줌(메뉴의 "들어 있는 폴더 열기"). **정렬**: 최근 고친 순 / 이름 순(2단원 < 10단원)
- 구글 드라이브를 연결하면 폴더 정리도 다른 기기와 맞춰짐. 두 기기에서 따로 정리해도 충돌 사본 없이 모두 반영(폴더·문서마다 나중에 바꾼 쪽). 문서를 옮겨도 문서 자체는 다시 올리지 않음

**길게 누르기 메뉴**

- 펜이나 손가락으로 화면을 **길게 누르면**(누른 자리에 원이 차오른 뒤) 메뉴가 열림. PC는 **마우스 오른쪽 클릭**
- 글상자·링크 위: 링크 열기("N쪽으로 가기") · 글자 고치기 · 링크 걸기/바꾸기 · 크기·위치 조절 · **복사 · 잘라내기 · 복제 · 붙여넣기** · 지우기
- 빈 곳: **여기에 붙여넣기** · 여기에 글상자 · 여기에 링크 · 실행 취소/다시 실행 · 이 페이지 필기 지우기 · 뒤에 빈 페이지 추가 · 이 페이지 복제 · (웹 페이지) 새로고침 · 강의 모드 · (감췄으면) 펜 바 보이기
- 펜으로 길게 누를 때 찍힌 점은 남지 않음. 움직이며 쓰거나 짧게 콕 찍는 것은 평소처럼 필기, 지우개로 지우는 중에는 열리지 않음

**텍스트 상자·하이퍼링크**

- 도구 막대의 **텍스트(T)**: 페이지를 누르면 글상자가 생기고 바로 입력. 상자를 누르면 고르기(끌어서 옮기기), 한 번 더 누르면 글 고치기
- 고른 상자 위 막대: 글자 고치기 · **링크** · 글자 작게/크게 · 글자색 4가지 · **복사 · 잘라내기** · 지우기(알림의 "되돌리기"로 복구)
- **상자 크기 조절**: 고른 상자의 오른쪽(가로)·아래(세로)·모서리(둘 다) 손잡이를 끌면, 상자 폭에 맞춰 줄이 바뀌고 글자 크기가 상자를 꽉 채우도록 저절로 커지고 작아짐. 글을 더 쓰면 같은 상자 안에서 글자가 줄어듦. 크기를 정한 상자에서 글자 작게/크게는 상자를 함께 줄이고 키움
- **붙여넣기**: 복사·잘라낸 상자가 있으면 도구 막대에 붙여넣기 버튼이 생김. 링크·글자 모양 그대로, 같은 자리에 붙고(겹치면 조금 비켜서) 다른 문서에도 붙일 수 있음
  - 페이지 링크를 다른 페이지에 붙이면 연결한 페이지에 그 페이지로 돌아가는 링크도 생김. 잘라내서 붙이면 링크와 돌아가기 링크가 함께 옮겨 감
  - 다른 문서에 붙인 페이지 링크는 연결이 풀리고 글자만 남음
  - PC 키보드: 고른 상자 **Ctrl+C / Ctrl+X**, **Ctrl+V**. 다른 앱에서 복사한 글을 Ctrl+V 하면 새 글상자(웹 주소면 링크 상자)
- **링크 만들기(🔗)**: 링크 상자를 만들고 바로 연결할 곳을 고름 — **이 문서의 페이지** 또는 **웹 주소**
- 페이지 링크를 걸면 연결한 페이지 오른쪽 위에 **"↩ N쪽으로 돌아가기"** 링크가 자동으로 생김 (끄는 칸 있음). 원래 링크를 지우거나 다른 페이지로 바꾸면 돌아가기 링크도 따라 지워지거나 옮겨감
- 글자를 비워 둔 페이지 링크는 "N쪽으로 가기 →"로 보이고, 페이지 순서를 바꾸면 쪽 번호가 저절로 맞춰짐
- 링크는 필기와 헷갈리지 않게 **단추 모양**(연한 파랑 바탕·테두리·그림자, 앞에 🔗 페이지 링크 / ↗ 웹 주소 아이콘, 밑줄 없음). 연결이 끊긴 링크는 회색에 가운데 줄
- 평소(펜 모드)에는 링크만 누를 수 있고 나머지 글자 위로는 필기가 그대로 지나감. 강의 모드에서도 링크 동작
- 웹 주소 링크는 브라우저(APK는 기본 브라우저 앱)로 열림

**강의 모드**

- 상단 바의 파란 **강의 모드** 단추(PC는 **F5**): 도구 막대·페이지 바가 숨고 페이지가 화면 가득 커짐. 브라우저에서는 전체 화면도 켜짐
- 왼쪽 펜 팔레트와 넘기기 바는 남음. 넘기기 바에 실행 취소·지우개·(웹앱·동영상) 판서/조작·끝내기 버튼이 붙음
- 끝내기: 바의 끝내기 버튼, **Esc**, 안드로이드 **뒤로 가기**

**저장과 문서 목록**

- 고치는 즉시 기기 안(IndexedDB)에 자동 저장. 앱을 다시 켜면 마지막에 보던 문서가 그대로 열림
- 홈(상단 ‹ 버튼) = 문서 목록: **PDF로 새 수업** · **빈 노트** · **파일 가져오기** · 샘플, 문서마다 이름 바꾸기·파일로 내보내기·삭제
- 편집 화면에서 제목을 누르거나 상단 **⋮ 더보기 → 이름 바꾸기**, **더보기 → 파일로 내보내기**(`.lessondeck` = 페이지 구성·필기·원본을 묶은 zip). 안드로이드에서는 공유 창으로 카카오톡·드라이브 등에 바로 보냄

**구글 드라이브 백업·자동 동기화**

- 상단 구름 버튼 → **구글 계정 연결**. 문서·필기·원본이 드라이브의 레슨덱 전용 숨김 공간(`appDataFolder`)에 올라감 (내 드라이브 목록에는 안 보이고, 레슨덱은 다른 드라이브 파일을 볼 수 없음)
- 다른 태블릿·휴대폰에 앱을 깔고 같은 계정을 연결하면 문서를 모두 받아 오고, 이후 자동으로 맞춤: 앱을 켤 때 · 고친 뒤 15초 · 앱을 내릴 때 · 인터넷이 다시 연결될 때 · 켜 두는 동안 3분마다
- 두 기기에서 같은 문서를 동시에 고치면 한쪽을 "제목 (다른 기기)" 사본으로 남겨 아무것도 잃지 않음. 한 기기에서 지운 문서는 다른 기기에서도 지워짐
- 원본(PDF·동영상 등)은 한 번만 올리고, 자주 바뀌는 필기는 압축해서 따로 올림. 5MB가 넘는 파일은 이어 올리기
- 처음 한 번 Google Cloud 설정이 필요합니다 → 아래 [구글 드라이브 연결 설정](#구글-드라이브-연결-설정-처음-한-번)

**이미지·동영상**

- 페이지 추가 메뉴의 **이미지…**: 여러 장을 한꺼번에 골라 넣으면 그림마다 그 비율의 페이지가 생김. PNG·JPEG·WebP·GIF(움직임)·SVG·BMP·AVIF·ICO, 갤럭시·아이폰 사진(HEIC/HEIF → JPEG), 스캔 TIFF(→ PNG). 4096px보다 큰 사진은 줄여서 저장
- **동영상…**: 기기에 저장된 MP4·WebM·MOV 등. 페이지 안에서 재생(인터넷 불필요), 판서 모드로 바꾸면 멈춘 화면 위에 필기, 다른 페이지로 넘어가면 일시정지. 페이지 바 썸네일에 첫 화면과 길이 표시

**유튜브 동영상**

- 페이지 추가 메뉴의 **유튜브 동영상…**에 링크를 붙여넣으면 창을 바꾸지 않고 페이지 안에서 바로 재생 (웹 주소 칸에 붙여넣어도 알아봄)
- 일반·짧은(youtu.be)·Shorts·라이브·재생목록 링크와 시작 시각(`t=1m30s`) 지원
- 조작 모드에서 재생·일시정지, 판서 모드로 바꾸면 멈춘 화면 위에 필기
- 다른 페이지로 넘어가면 자동으로 일시정지 (숨겨 둔 영상에서 소리가 나지 않게)
- 영상 주인이 삽입을 막은 영상은 안내와 함께 "YouTube에서 열기" (APK에서는 유튜브 앱으로 열림), 오른쪽 위 배지로도 언제든 열 수 있음
- 인터넷 필요. 페이지 바에는 영상 썸네일 표시

**HTML·URL 페이지**

- 페이지 추가 메뉴의 **HTML 파일…**: 파일 내용을 문서 안에 넣어 서버·인터넷 없이 실행 (`iframe srcdoc` + sandbox, 레슨덱 데이터에 접근 불가)
- **웹 주소(URL)…**: 이미 배포된 웹앱(형성평가 멀티툴 등). 오른쪽 위에 늘 "브라우저에서 열기"
  - 불러오는 동안 안내, 15초가 지나도 안 열리면 원인 안내와 **다시 시도 · 브라우저에서 열기 · 그래도 보기**, 오프라인이면 다시 연결될 때 저절로 다시 불러옴
  - 구글 슬라이드·문서·시트·설문·드라이브 파일, 캔바 디자인 링크는 그대로 붙여넣으면 페이지 안에 넣을 수 있는 주소로 바꿔서 띄움 (공개 또는 링크 공유된 파일)
  - 안드로이드 앱: "다른 앱 안에 띄우지 마세요" 설정이 있는 사이트도 앱 안에 보이게 처리하고, 사이트 안의 링크·이동이 바깥 브라우저로 튀어 나가지 않음. 로그인이 필요한 사이트(제3자 쿠키), http 사이트도 열림
- 넣을 때 외부 라이브러리(CDN)·같은 폴더 파일·localStorage 사용을 찾아 알려 줌 (SPEC R4·R6), EUC-KR 파일도 읽음
- 기본은 **조작 모드**(손가락·펜으로 웹앱 사용). 툴바의 **판서** 스위치나 펜·형광펜·지우개를 고르면 판서 모드(파란 테두리), 다시 **조작**으로 돌아가도 필기는 남음
- 웹앱은 16:9(1280×720)·4:3(1024×768)·A4(794×1123) 가상 화면으로 그려 페이지에 맞춰 축소·확대 → TV 미러링에서도 잘리지 않음. 비율은 페이지 바에서 바꿈
- 최근 연 웹 페이지 3개는 닫지 않고 숨겨 둬서, 넘겼다 돌아와도 퀴즈 진행 상태가 유지됨
- **새로고침**: HTML·웹 주소·유튜브 페이지에서 도구 막대의 ⟳ 버튼(강의 모드는 넘기기 바)으로 처음 상태부터 다시 불러옴 (다음 반 수업 전 퀴즈 초기화 등)
- 웹앱 안의 스와이프와 겹치지 않도록 HTML·URL 페이지에서는 쓸어 넘기기 대신 아래쪽 ‹ › 버튼 사용
- **숨기기**: HTML로 대체한 PDF 쪽 등을 지우지 않고 숨김. 넘길 때 건너뛰고 페이지 바에서 흐리게 보임

**페이지**

- 왼쪽 페이지 바(상단 ▯ 버튼으로 열고 닫기): 썸네일(필기·글상자 포함), 썸네일 사이 `+`로 그 위치에 추가
- HTML 페이지 썸네일은 실제 화면을 작게 실행해 보여 주고(보이는 동안만), 왼쪽 아래에 파일 이름 표시
- 추가: 빈 페이지 · 모눈 페이지 · PDF 파일의 전 쪽 · 이미지 · 동영상 · HTML · 웹 주소 · 유튜브 (상단 📄+ 버튼은 현재 페이지 뒤에 추가)
- **끌어서 옮기기**: S펜·마우스는 썸네일을 잡고 바로 끌고, 손가락은 0.35초 길게 누른 뒤 끌기. 놓을 자리에 파란 줄이 보이고, 목록 위·아래 끝으로 가면 저절로 스크롤
- 선택한 페이지: 앞으로·뒤로 이동, 복제, 삭제(알림의 "되돌리기"로 복구). 마지막 한 장은 삭제할 수 없음
- 페이지 넘기기: 손가락으로 좌우로 쓸기, 아래쪽 ‹ › 버튼, PC는 ←/→ 키
- **넘기기 바 옮기기**: 바 왼쪽 손잡이(⋮⋮)나 쪽수를 잡고 끌면 화면 어디로든 이동. 자리는 기억되고, 손잡이를 두 번 누르면 아래 가운데로 돌아감
- 실행 취소는 페이지마다 따로 동작

**손가락**

- 두 손가락으로 확대(최대 5배)·이동, 확대 상태에서는 한 손가락으로 이동, 두 번 탭하면 원래 크기
- 확대를 마치면 그 배율로 PDF와 필기를 다시 그려 선명하게 보임
- 펜을 쓰는 중(또는 직후 0.8초)의 터치는 손바닥으로 보고 무시

**필기 (Phase 0)**

- 샘플 PDF(`public/sample.pdf`, 필기감 시험지)를 pdfjs-dist로 렌더링
- 그 위에 S펜 필기 캔버스: perfect-freehand + 필압, `getCoalescedEvents()`·`getPredictedEvents()`
- 진행 중인 획은 별도 캔버스(저지연 `desynchronized` 옵션)에만 그리고, 펜을 떼면 아래 캔버스에 합성
- 펜·형광펜·지우개(획 단위), 색 5개·굵기 3단계, 실행 취소/다시 실행, 페이지 필기 지우기
- S펜 = 필기, 손가락 = 넘기기·확대. 상단 ✋ 버튼으로 "손가락으로도 필기" 전환 (이때 두 손가락은 확대)
- 왼쪽 **펜 바**: 위쪽 손잡이(⠿)를 잡고 끌어 어디로든 옮김(자리 기억), 손잡이를 누르면 접기/펼치기, 아래 눈 버튼으로 감추기 → 도구 막대의 팔레트 버튼(강의 모드에서는 넘기기 바의 팔레트 버튼)으로 다시 보이기
- S펜 사이드 버튼을 누르고 있는 동안 지우개 (툴바 지우개 버튼이 켜지고, 떼면 펜으로 돌아감)
- 오른쪽 아래 디버그 패널: `pointerType`, `pressure`, `buttons`, 기울기, 이벤트 빈도, 입력 지연, Phase 0 체크리스트, 검증 결과 복사
- PWA: 홈 화면 설치(전체 화면), pdf.js 워커·한글 cmaps·샘플 PDF까지 사전 캐시해 오프라인 동작

## 안드로이드 앱 (APK)

웹앱을 [Capacitor](https://capacitorjs.com)로 감싼 안드로이드 앱입니다. 앱 파일이 APK 안에 모두 들어 있어서 인터넷 없이 동작하고, 배포 주소도 필요 없습니다.

- **화면**: 상태 표시줄·내비게이션 바를 숨긴 전체 화면으로 열립니다. 수업 중에는 화면이 꺼지지 않습니다.
- **뒤로 가기**: 2초 안에 두 번 눌러야 앱이 닫힙니다. 수업 중 실수로 닫히는 것을 막기 위해서입니다.
- **글꼴 크기**: 기기의 글꼴 크기 설정과 관계없이 화면 배치가 유지됩니다.

### APK 받기 (GitHub Actions)

`lessondeck/`이 바뀐 커밋을 푸시하면 GitHub Actions의 **LessonDeck APK** 워크플로가 APK를 빌드합니다.

1. 저장소의 **Actions** 탭에서 **LessonDeck APK**를 고르고, 맨 위(최신) 실행을 엽니다.
2. 아래쪽 **Artifacts**에서 `lessondeck-<번호>-<커밋>.apk`를 내려받습니다. zip 파일로 받아지니 압축을 풉니다.
3. 태블릿에서 APK를 누릅니다. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

모든 빌드가 저장소에 들어 있는 같은 디버그 키(`android/app/lessondeck-debug.keystore`)로 서명됩니다. 그래서 새 APK를 지우지 않고 기존 앱 위에 덮어 설치할 수 있습니다. 단, v0.5.1에서 이 키를 새로 만들었으므로(구글 드라이브 연결용 지문 충돌 해결) 그 전 APK가 깔려 있으면 한 번은 지우고 새로 설치해야 합니다. 지우기 전에 남길 문서는 "파일로 내보내기"로 백업하세요. 이 키는 기기에 직접 설치하는 시험용입니다. Play 스토어에 올리려면 배포용 키를 따로 만들어 비밀로 보관해야 합니다.

### 직접 빌드 (Windows PC)

[Android Studio](https://developer.android.com/studio)를 설치한 뒤 PowerShell에서 실행합니다.

```powershell
cd lessondeck
npm run android:sync          # 웹 빌드 후 android/ 프로젝트에 복사
cd android
.\gradlew.bat assembleDebug   # → app\build\outputs\apk\debug\app-debug.apk
```

Android Studio에서 열려면 `npx cap open android`를 실행합니다. USB로 연결한 태블릿에 바로 설치하며 시험할 수 있습니다.

### 구글 드라이브 연결 설정 (처음 한 번)

앱이 구글 드라이브에 접근하려면 Google Cloud에 "레슨덱" 앱을 등록해야 합니다. 앱 안에 비밀번호·키는 넣지 않고, 구글이 **패키지 이름 + 서명 지문(SHA-1)**으로 이 앱을 알아봅니다. 설정 후 앱을 다시 빌드할 필요는 없습니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 사용 설정합니다.
3. **OAuth 동의 화면**(Google 인증 플랫폼): 앱 이름 "레슨덱", 사용자 유형 **외부**. **데이터 액세스(범위)**에 `https://www.googleapis.com/auth/drive.appdata`를 추가하고, **대상 → 테스트 사용자**에 쓸 구글 계정을 넣습니다. (`drive.appdata`는 민감하지 않은 범위라 테스트 상태로 계속 써도 되고, 여러 사람이 쓰려면 "앱 게시"를 누릅니다.)
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → Android**
   - 패키지 이름: `kr.lessondeck.app`
   - SHA-1 인증서 지문: `F8:DD:CE:A1:7A:85:04:B6:35:69:A9:5D:CC:66:A2:D5:88:20:08:A8` (저장소의 디버그 키. GitHub Actions APK가 모두 이 키로 서명됨)
5. 태블릿의 레슨덱에서 상단 구름 버튼 → **구글 계정 연결**.

"Google Cloud 설정이 앱과 맞지 않습니다(DEVELOPER_ERROR)"가 뜨면 4번의 패키지 이름·SHA-1을 다시 확인하세요. 설정이 반영되기까지 몇 분 걸릴 수 있습니다.

**웹 버전(Vercel)**에서 쓰려면 같은 프로젝트에 **웹 애플리케이션** OAuth 클라이언트를 만들고(승인된 JavaScript 원본에 배포 주소 추가), 그 클라이언트 ID를 빌드 환경 변수 `VITE_GOOGLE_CLIENT_ID`로 넣습니다.
